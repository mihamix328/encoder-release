ИНСТРУКЦИЯ ДЛЯ macOS


1. УСТАНОВКА

Распакуйте ZIP обычного клиента и админ-панели.
Перенесите Encoder.app и Encoder Admin.app в папку Applications.
Дополнительные библиотеки устанавливать не нужно.
Подключите питание и Ethernet; настройку IP на Mac оставьте автоматической.
Если плата ещё не настроена на локальное имя, используйте её известный IP.

Если macOS блокирует запуск, после попытки открытия разрешите приложение
в «Системные настройки → Конфиденциальность и безопасность».


2. ПОЛУЧЕНИЕ СЕРТИФИКАТА

Откройте приложение «Терминал» на Mac.
Для настроенной платы используйте имя orangepi3b.local,
а root — вашим SSH-пользователем, если он другой.
Пароль SSH может отличаться от пароля клиента Encoder.

Выполните на Mac:

scp root@orangepi3b.local:/etc/encoder/certs/server.crt "$HOME/Downloads/server.crt"

Введите пароль SSH. Символы пароля при вводе не отображаются.
При первом подключении сверьте отпечаток SSH-ключа платы перед подтверждением.
Сертификат появится в папке «Загрузки».
Скачивайте только server.crt. Приватный server.key остаётся на плате.


3. ОБЫЧНЫЙ КЛИЕНТ

Откройте Encoder.app и укажите:

Сервер: orangepi3b.local (для настроенной платы).
Порт: 7443, если на сервере не настроен другой.
Сертификат: нажмите «Выбрать…» и укажите скачанный server.crt.
Логин и пароль: учётная запись пользователя Encoder.

Нажмите «Подключиться».
Не перемещайте сертификат после выбора, иначе его потребуется выбрать заново.
Первое шифрование и расшифрование проверьте на копии ненужного файла:
при шифровании клиент заменяет исходный файл.


4. СЕРТИФИКАТ ДЛЯ АДМИН-ПАНЕЛИ

Один раз откройте и закройте Encoder Admin.app.
Затем выполните в Терминале на Mac:

cp "$HOME/Downloads/server.crt" "$HOME/Library/Application Support/encoder/admin/config/server.crt"

Если сертификат в этой папке уже есть, команда заменит его.


5. ПОЛУЧЕНИЕ АДМИН-ТОКЕНА

В Терминале на Mac подключитесь к плате:

ssh root@orangepi3b.local

Введите пароль SSH. Затем внутри открытого SSH-сеанса выполните:

sudo sed -n 's/^[[:space:]]*admin_token[[:space:]]*=[[:space:]]*//p' /etc/encoder/server.conf

Команда покажет токен. Скопируйте только его значение.
При входе root команду можно выполнить без sudo.
Чтобы выйти из SSH-сеанса, введите:

exit

Токен нужен только админ-панели. Он не равен паролю пользователя admin.
Не публикуйте токен и не отправляйте его вместе со сборкой приложения.
Для подключения Mac менять существующий токен сервера не нужно.


6. ПОДКЛЮЧЕНИЕ АДМИН-ПАНЕЛИ

Откройте Encoder Admin.app и нажмите «Добавить устройство».

Имя: любое удобное название платы.
Хост: orangepi3b.local (для настроенной платы).
Порт: 7444, если на сервере не настроен другой.
Токен: значение, полученное через SSH.

Выберите добавленное устройство в списке.
Для работы достаточно локальной связи с платой, в том числе по Ethernet.
Интернет не требуется.


7. ЕСЛИ НЕ ПОДКЛЮЧАЕТСЯ

Ошибка SSH: проверьте SSH-логин и пароль, а не пароль Encoder.

Ошибка сертификата: проверьте путь к файлу и адрес платы.
Адрес подключения должен соответствовать имени или IP в сертификате.
Проверку TLS не отключайте.

Unauthorized в админ-панели: проверьте токен и административный порт.

Нет соединения: проверьте адрес, сеть и доступность нужного порта.
Например, в Терминале на Mac:

nc -vz -w 3 orangepi3b.local 7443
nc -vz -w 3 orangepi3b.local 7444

Если сертификат или конфигурация не найдены по указанным путям,
в SSH-сеансе платы выполните:

sudo systemctl cat encoder-server

В строке ExecStart найдите путь после --config.
Используйте этот файл вместо /etc/encoder/server.conf в команде получения токена.
Путь сертификата можно посмотреть на плате командой:

sudo grep '^cert_file=' /etc/encoder/server.conf

Если SSH-доступа нет, получите сертификат и токен у администратора платы.
